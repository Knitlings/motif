Instructions for

Pattern

↑ Contents

Draw a single repeat of your pattern—the preview will show how it tiles.

Paint

Click a cell to paint it with the active pattern colour. Click and drag to paint multiple cells at once.

Tap a cell to paint it with the active pattern colour.

Erase

Click a painted cell to toggle between the background colour and the active pattern colour.

Tap a painted cell to toggle between the background colour and the active pattern colour.

Hold Shift and click cells to paint with the background colour instead of the active colour.

Click the × after the caption below the pattern to clear the entire pattern to the background colour.

Tap the × after the caption below the pattern to clear the entire pattern to the background colour.

Resize

To resize the pattern, you can:

  • Enter the number of stitches and rows in the caption below the pattern.
  • Drag the edges of the pattern to shrink and enlarge it.

A pattern too large for the page scrolls inside its frame. It has no edges to drag, so resize it with the numbers in the caption.

Drag inside the frame to move around the pattern. Drag anywhere else to move the page.

Preview

↑ Contents

The preview shows several repeats of your pattern, so you can see how it connects when repeating and catch problems that only appear when the pattern is tiled.

Adjusting preview repeats

You can change how many times the pattern repeats horizontally and vertically by entering the desired number of repeats in the caption above the preview.

The maximum number of repeats depends on your pattern's largest dimension to keep the preview running smoothly:

Largest dimensionMaximum repeats
15 and smaller10×10
16 to 198×8
20 to 266×6
27 to 315×5
32 to 394×4
40 to 523×3
53 to 792×2
80 and larger1×1

For example, a 2×20 pattern has a largest dimension of 20, so it allows up to 6×6 repeats.

When you resize your pattern larger, the preview repeats will automatically reduce if needed. A status message appears when you're near or at the maximum for your pattern size.

Colours

↑ Contents

The pattern colours are shown in the key below the pattern, numbered from 1. The active pattern colour is outlined. Motif keeps track of what cells use what pattern colour, so you can easily change them all at once and try new combinations.

If there are more pattern colours than fit in the key, a button such as +3 shows the remaining colours.

Changing and deleting pattern colours

Click a pattern colour to select it. Click the selected colour again to change or remove it.

Tap a pattern colour to select it. Tap the selected colour again to change or remove it.

You can also directly select a pattern colour using the keyboard: 1–9, 0 for pattern colours 1–10, and the same with Shift for pattern colours 11–20.

The first pattern colour can't be removed.

Adding pattern colours

Click the + button to add a new pattern colour. You can add up to 20 colours per pattern.

Tap the + button to add a new pattern colour. You can add up to 20 colours per pattern.

Swapping colours

Drag one pattern colour onto another to merge their positions and remove the target colour. You can also drag pattern colours to the background colour to merge them.

Background colour

This is the default colour for cells. It has its own place in the key, labelled Background.

Click the background colour to change it. Click a painted cell to toggle between the background colour and the active pattern colour. Hold Shift and click cells to turn them into background.

Tap the background colour to change it. Tap a painted cell to toggle between the background colour and the active pattern colour. Long-press the background colour and then tap cells to turn them into background.

Palette

Palettes are curated selections of colours you can easily apply to your pattern colours. The key shows the selected palette's name and its colours.

Click the palette's name to select another one.

Tap the Palette row to see the palette's colours or select another one.

Click a palette colour to set it as the active pattern colour.

Tap a palette colour to set it as the active pattern colour.

Hold Shift and click a palette colour to set it as the background colour.

Long-press a palette colour to set it as the background colour.

Click Load palette to apply the current palette to the pattern colours, replacing them.

Tap Load palette to apply the current palette to the pattern colours, replacing them.

Click Custom to edit your own palette. Click a colour in the custom palette to select, edit or delete it. Click the + button to add a new colour to the custom palette.

Tap Custom to edit your own palette. Tap a colour in the custom palette to select, edit or delete it. Tap the + button to add a new colour to the custom palette.

Undo and redo

↑ Contents

Click the curved arrow buttons after the caption below the pattern to undo and redo your changes.

Tap the curved arrow buttons after the caption below the pattern to undo and redo your changes.

You can also use Cmd/Ctrl + Z to undo and Cmd/Ctrl + Y to redo.

Download

↑ Contents

Click the Download button after the caption above the preview to open the download dialogue.

Tap the Download button after the caption above the preview to open the download dialogue.

Download options

  • Source:
    • Pattern: Single repeat of the pattern as shown in the pattern grid.
    • Pattern repeat with surroundings: One repeat plus your selection of neighbouring rows or columns.
    • Preview: Multiple tiled repeats as shown in the preview.
  • Format: Choose between PNG or SVG.
  • Include row counts: Add row count numbers to the right side of your downloaded image.

Pattern repeat with surroundings

When you select Pattern repeat with surroundings, you can specify how many neighbouring rows and columns to include.

For smaller patterns you'll see a visual selection mode where you can drag the edges on the preview to choose your surrounding area, or enter the numbers in the caption above the preview.

For larger patterns, use the form inputs to enter the number of rows and columns you want to include next to the pattern repeat.

Settings

↑ Contents

Access these options in the Menu:

Import/Export

Click Import JSON to load a previously saved Motif JSON file. The JSON file contains your pattern dimensions, cell aspect ratio, colour palette, pattern data, and preview settings in a human-readable format that can be manipulated programmatically.

Tap Import JSON to load a previously saved Motif JSON file. The JSON file contains your pattern dimensions, cell aspect ratio, colour palette, pattern data, and preview settings in a human-readable format that can be manipulated programmatically.

Click Export JSON to create a JSON file you can import later.

Tap Export JSON to create a JSON file you can import later.

Cell aspect ratio

Click the drop down to choose from preset ratios like "Square 1:1" or "Knit stitch 4:3". To set a custom aspect ratio, click Custom and enter a decimal (e.g. 1.25) or a ratio (e.g. 3:4). You can also drag the slider.
